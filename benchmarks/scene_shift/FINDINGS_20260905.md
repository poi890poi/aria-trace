# Whole-scene shift findings — 2026-09-05

## Decision

Do not replace accurate KLT in free-roam tracking with the tested lower-cost
methods. Route-assisted tracking should bypass scene KLT entirely because that
branch consumes direct current-frame map correlation and does not use scene
motion.

The full chronological evidence is in
`artifacts/poc/scene-shift-full-20260905`. Run 17 is the development traversal;
Run 18 is the independently recorded reverse traversal. Both contain about
5,400 frames at 30 FPS and timestamped raw mouse input.

## Complete replay result

The 960 px / 800-corner / forward-backward / essential-gated KLT reference
produced 99.9% fresh observations. Its worst-session P95 was 31.40 ms, with
97.2% of all frames fresh within 33.3 ms. This is an offline comparison
reference, not physical ground truth.

The best lower-cost candidate was 640 px KLT:

- P95 latency improved from 31.40 ms to 16.06 ms;
- fresh-within-33.3-ms coverage improved from 97.2% to 99.8%;
- Run 17 reference disagreement was 0.07 degree P95 and 6.70 degrees worst;
- Run 18 disagreement degraded to 0.18 degree P95 and 9.41 degrees worst;
- accumulated disagreement reached 118.25 degrees on Run 18;
- input-to-scene correlation was 0.70 versus 0.75 for the reference.

The 480 px / 200-corner candidate reached 12.89 ms P95 but degraded further on
Run 18: 0.26 degree P95, 8.27 degrees worst, and 166.55 degrees accumulated
disagreement. More aggressive 320 and 240 px resizing stayed fast but did not
restore consistency.

Gray phase correlation reached 6.76 ms P95 and 100% raw availability, but its
Run 18 disagreement was 0.88 degree P95, 5.16 degrees worst, and 423.07 degrees
accumulated. Its input correlation was only 0.39. It is rejected as a control
measurement.

Frame stride two produced only 49.9% fresh coverage in the bounded screen. It
is rejected regardless of its low compute time because a held state is not a
fresh 30 FPS measurement.

## Evidence boundaries

Agreement with the accurate KLT reference measures implementation consistency,
not real angular accuracy. Raw input independently supports direction and lag,
not angle magnitude. The reverse traversal is essential: the 600-frame Run 17
screen made 480/200 KLT appear acceptable, while the full holdout disproved it.

The next scene-yaw research step should target the rare catastrophic lower-scale
KLT errors rather than further uniform downsampling. No such temporal wrapper
is landed here because it would be a new variable requiring its own complete
chronological replay.
